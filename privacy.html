merchingirl-n8n(이하 “앱”)은 팟캐스트 ‘멋찐걸’의 운영자가 본인 1명의 Google 계정으로만 사용하는 개인용 자동화 도구입니다. 이 방침은 앱이 어떤 Google 데이터에 접근하고, 왜 접근하며, 어떻게 보관·삭제하는지 설명합니다.

1. 수집·접근하는 정보

앱은 운영자 본인의 Google 계정에서 아래 정보에만 접근합니다. 다른 사람의 계정 데이터는 수집하지 않습니다.

2. Google API Services 사용자 데이터 정책 준수

앱은 Google API Services로부터 받은 정보를 Google API Services User Data Policy(제한적 사용 요구사항 포함)에 따라 사용합니다. Google API에서 받은 데이터는 앱의 기능(예약 발행) 수행 목적으로만 사용하며, 판매·대여·광고·신용평가·대출 목적으로 사용하거나 제3자에게 제공하지 않습니다. 사람이 해당 데이터를 열람하는 것은 운영자가 직접 확인을 요청한 경우, 보안 문제 대응, 법령상 의무 이행의 경우로 한정됩니다.

3. 데이터의 저장과 처리 위치

  • 영상·이미지 파일과 예약표는 운영자 본인의 Google 계정에 그대로 보관됩니다.
  • 자동화 서버는 운영자가 직접 운영하는 자체 호스팅 n8n 인스턴스이며, 처리하는 동안에만 파일을 임시로 내려받아 업로드에 사용합니다.
  • OAuth 액세스 토큰·리프레시 토큰은 그 서버의 암호화된 자격증명 저장소에만 저장되고, 제3자 서버로 전송되지 않습니다.
  • 발행 기록(성공/실패, 발행 시각, 번역 캡션)은 운영자의 Google Sheets 예약표에 기록됩니다.

4. 보관 기간과 삭제

  • 데이터는 앱을 사용하는 동안 보관되며, 운영자가 예약표·Drive 파일을 삭제하면 즉시 사라집니다.
  • Google 계정의 보안 > 타사 앱 액세스에서 언제든 앱의 접근 권한을 해제할 수 있습니다. 해제 즉시 서버의 토큰은 더 이상 사용할 수 없게 됩니다.
  • 삭제 요청은 아래 문의 이메일로 보내주시면 확인 후 지체 없이 처리합니다.

5. 제3자 제공 및 이전

앱은 Google 사용자 데이터를 제3자에게 판매·대여·공유하지 않습니다. 다만 운영자가 예약표에 지정한 대상 채널 (YouTube, Instagram, Threads)로 운영자 본인의 콘텐츠를 게시하기 위해 해당 서비스의 공식 API로 콘텐츠와 캡션을 전송합니다.

6. YouTube API Services

앱은 YouTube API Services를 사용합니다.

  • 앱을 사용함으로써 YouTube 서비스 약관에 동의하게 됩니다.
  • Google 개인정보처리방침이 적용됩니다.
  • Google 계정의 보안 설정 페이지에서 앱의 데이터 접근 권한을 관리·해제할 수 있습니다.

7. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 운영자 외 누구의 정보도 수집하지 않습니다.

8. 방침의 변경

이 방침이 바뀌면 이 페이지에 개정일과 함께 게시합니다. 중요한 변경이 있는 경우 운영자 이메일로도 안내합니다.

Privacy Policy (English)

Effective: November 26, 2026

merchingirl-n8n is a private, single-user automation used only by the operator of the podcast “Merchingirl” with the operator’s own Google account. It is not offered to the public and does not collect or access any other person’s Google data.

Data accessed

  • https://www.googleapis.com/auth/drive — to list and download the operator’s own video/image files from an upload folder and move published files to an archive folder.
  • https://www.googleapis.com/auth/spreadsheets — to read the publishing schedule and write publishing results back to the operator’s spreadsheet.
  • https://www.googleapis.com/auth/youtube.upload — to upload the operator’s own videos to the operator’s own YouTube channel.

Google API Services User Data Policy

The app’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the publishing feature, is not sold, rented, or shared with third parties, and is not used for advertising, credit, or lending purposes.

Storage and deletion

Files remain in the operator’s own Google account. OAuth tokens are stored only in the operator’s self-hosted n8n server. Access can be revoked at any time on the Google Account permissions page, and deletion requests can be sent to merchingirlspod@gmail.com.

YouTube API Services

This app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. You can manage or revoke the app’s access on the Google security settings page.
