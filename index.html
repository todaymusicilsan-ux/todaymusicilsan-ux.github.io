Personal automation · 개인용 자동화 도구

merchingirl-n8n 팟캐스트 ‘멋찐걸’의 짧은 영상·이미지를 Google Drive → Google Sheets → YouTube로 예약 발행하는 1인용 도구입니다.

운영: 유림 왕 (멋찐걸 · Merchingirl) · 문의: merchingirlspod@gmail.com

이 앱은 무엇인가요?

merchingirl-n8n은 제가 운영하는 팟캐스트 ‘멋찐걸’의 콘텐츠를 제가 정한 시간에 제 사회관계망(YouTube Shorts · Instagram Reels · Threads)에 올리기 위해 직접 만든 개인용 자동화 도구입니다.

  • 사용자는 운영자 본인 1명입니다. 회원가입, 결제, 일반 공개 사용은 없습니다.
  • 다른 사람의 Google 계정 데이터를 수집하거나 열람하지 않습니다. 접근하는 데이터는 운영자 본인의 Google Drive·Sheets·YouTube뿐입니다.
  • Google API로 받은 데이터를 판매·광고·제3자 제공에 사용하지 않습니다.

어떻게 동작하나요?

① Drive 폴더에 영상·이미지 업로드 ② 예약 시트에 시간·캡션 입력 ③ 15분마다 예약 확인 ④ YouTube·Reels·Threads 발행 ⑤ 결과 기록 · 아카이브 이동

제가 Google Drive의 ‘01_업로드할_영상’ 폴더에 영상을 올리고, Google Sheets 예약표에 올릴 시간과 캡션을 적으면, 워크플로우(n8n)가 예약 시간이 된 항목을 찾아 해당 채널에 업로드하고, 결과를 같은 시트에 기록한 뒤 파일을 아카이브 폴더로 옮깁니다.

자동화 엔진은 운영자가 직접 운영하는 자체 서버(Railway에 배포한 n8n 인스턴스)에서 실행됩니다.

요청하는 Google 권한과 사용 목적

권한(Scope)무엇에 쓰나요
.../auth/drive 제 Drive의 ‘01_업로드할_영상’ 폴더에서 발행할 영상·이미지 파일을 찾아 내려받고, 발행이 끝난 파일을 ‘02_발행완료_아카이브’ 폴더로 옮기기 위해 사용합니다. 폴더 안 파일 목록을 읽어야 해서 Drive 전체 범위가 필요합니다.
.../auth/spreadsheets 발행 예약표(Google Sheets)에서 예약 시간·캡션·채널을 읽고, 발행 결과(성공/실패, 발행 시각)를 같은 표에 기록하기 위해 사용합니다.
.../auth/youtube.upload 제가 만든 짧은 영상을 제 YouTube 채널에 Shorts로 업로드하기 위해 사용합니다. 영상 제목·설명·공개 상태는 제가 예약표에 적은 값 그대로 전송됩니다.

자동화 도구(n8n)의 기본 설정상 위 범위에 속한 하위 범위가 함께 요청될 수 있지만, 앱이 접근하는 대상은 모두 운영자 본인의 Drive·Sheets·YouTube입니다. 다른 사람의 계정에는 접근하지 않으며, Google Workspace 관리자 권한이나 Gmail 접근은 사용하지 않습니다.

데이터는 어떻게 다루나요?

저장 위치

영상·이미지와 예약표는 제 Google 계정에 그대로 있고, 자동화 서버는 처리하는 동안에만 파일을 임시로 내려받습니다. OAuth 접근 토큰은 제가 운영하는 자체 서버의 암호화된 자격증명 저장소에만 보관됩니다.

제3자 제공

어떤 데이터도 판매·대여·광고에 사용하지 않고 제3자에게 제공하지 않습니다. Google API에서 받은 데이터는 앱의 발행 기능 수행 목적으로만 사용합니다.

보관과 삭제

발행 기록은 예약표에 남고, 필요 없어지면 제가 직접 삭제합니다. Google 계정의 보안 > 타사 앱 액세스에서 언제든 접근을 해제할 수 있으며, 해제하면 서버의 토큰도 더 이상 동작하지 않습니다.

YouTube API Services

이 앱은 YouTube API Services를 사용합니다. 앱을 사용함으로써 YouTube 서비스 약관과 Google 개인정보처리방침에 동의하게 됩니다.

About this app (English)

merchingirl-n8n is a private, single-user automation built by the operator of the podcast “Merchingirl” (멋찐걸). It publishes the operator’s own short-form videos and images to the operator’s own YouTube channel (Shorts), Instagram and Threads on a schedule.

It is not a public service: there is no sign-up, no payment, and no other user’s Google data is accessed.

How it works

The operator uploads a video to a Google Drive folder and adds a row (time, caption, target channels) to a Google Sheet. Every 15 minutes the workflow checks for due rows, uploads the matching file, writes the result back to the sheet, and moves the file to an archive folder.

Google scopes requested and why

  • https://www.googleapis.com/auth/drive — list and download the operator’s video/image files from the upload folder, and move published files to the archive folder.
  • https://www.googleapis.com/auth/spreadsheets — read the publishing schedule and write publishing results back to the operator’s spreadsheet.
  • https://www.googleapis.com/auth/youtube.upload — upload the operator’s own videos to the operator’s own YouTube channel as Shorts.

Data handling

No Google user data is sold, shared, or used for advertising. Files remain in the operator’s Google account; OAuth tokens are stored only in the operator’s self-hosted automation server. Access can be revoked at any time at Google Account permissions. This app uses YouTube API Services; by using it you agree to the YouTube Terms of Service and the Google Privacy Policy.
